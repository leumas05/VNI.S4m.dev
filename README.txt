S4m's Visual Network Intelligence (VNI) Engine
==============================================

Welcome to the VNI Engine!

This folder contains the core files required for the Electron Desktop Application to run properly. 

NOTE ON FOLDER STRUCTURE:
Due to strict requirements from the Chromium browser engine (which powers this app), all the .dll, .pak, and .bin files MUST be located in this exact root directory alongside the executable. Moving them into a subfolder will cause the application to crash permanently. 

To run the program, use the Start Menu shortcut or double-click "vni-engine.exe".

To uninstall the program, run "Uninstall VNI Engine.exe".

Enjoy your network intelligence!
